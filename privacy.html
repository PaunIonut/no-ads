Privacy Policy

Publisher: Paun Ionut. Effective date: July 11, 2026 (2026-07-11).

Data processed locally

The extension reads and modifies content on compatible YouTube pages solely to provide ad and promotional-interruption reduction. Page content and browsing activity are processed locally and are not received by the publisher.

Chrome preferences

Boolean choices for page cleanup, ad skipping, aggressive mode, and SponsorBlock are stored in chrome.storage.sync. Chrome may synchronize these preferences through the user's Chrome account. The publisher does not receive them.

Optional SponsorBlock feature

SponsorBlock is disabled by default. Only after the user enables it, the extension sends the third-party service https://sponsor.ajay.app a partial cryptographic prefix derived from the current video identifier and receives community-reported segments. This transfer is used only to provide the requested segment-skipping feature. The publisher does not sell this data or use it for advertising, profiling, creditworthiness, or lending purposes.

Public website

This website is hosted by GitHub Pages. The publisher has not added forms, first-party analytics, telemetry, or cookies. The hosting provider may process technical request data under its own privacy policy.

Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

What the extension does not do

  • It includes no first-party analytics or telemetry.
  • It uses no first-party cookies.
  • It does not contact a server operated by the publisher.
  • It does not include an external rules updater or remotely hosted code.
  • It does not sell user data or use it for personalized advertising.

Deletion

Users can remove the extension through Chrome. Synchronized preferences can be managed through the user's Chrome account.
