Politica de confidențialitate

Editor: Paun Ionut. Stare: politica publică a versiunii candidat. Data efectivă: 11 iulie 2026 (2026-07-11).

Date procesate local

Extensia analizează și modifică local conținutul paginilor YouTube compatibile. Editorul nu primește conținutul paginii sau istoricul de navigare.

Preferințe Chrome

Opțiunile booleene pentru curățarea paginii, saltul reclamelor, modul agresiv și SponsorBlock sunt păstrate în chrome.storage.sync. Chrome le poate sincroniza prin contul utilizatorului.

SponsorBlock opțional

SponsorBlock este oprit implicit. Numai după activare, extensia transmite serviciului terț https://sponsor.ajay.app un prefix criptografic parțial derivat din identificatorul videoclipului și primește segmente raportate de comunitate. Editorul nu vinde aceste date și nu le folosește pentru publicitate, profilare sau evaluarea eligibilității financiare.

Site-ul public

Site-ul este găzduit prin GitHub Pages. Editorul nu a adăugat formulare, analytics, telemetrie sau cookies proprii; furnizorul de găzduire poate însă procesa date tehnice ale cererii conform propriei politici de confidențialitate.

Limited Use

Utilizarea informațiilor primite prin API-urile Chrome respectă Politica privind datele utilizatorilor din Chrome Web Store, inclusiv cerințele Limited Use.

Ce nu face candidatul

  • Nu include analytics sau telemetrie proprie.
  • Nu folosește cookies proprii.
  • Nu contactează un server al editorului.
  • Nu include actualizare externă a regulilor.

Ștergere

Extensia poate fi dezinstalată din Chrome. Datele sincronizate pot fi administrate prin contul Chrome.
